# 答辩预设问答（陪练用）

> 本文件供 AI 助手对项目主人做答辩陪练：按清单提问，主人先自己答，答不上来再对照参考要点讲解。所有回答要点都来自本项目的真实实验过程，可以放心讲。回答建议控制在 30 秒以内，先给结论再给一句解释。

## 一、数据与实验类

**Q1：你的模型准确率多少？**
两个模型：BERT 90.47%，LSTM 基线 83.90%，在同一个 1,553 条的测试集上评估。老师要的模型对比就是这个：同一份数据、同一切分、同一口径，BERT 高出 6.57 个百分点。

**Q2：测试集参与训练了吗？怎么保证的？**
没有。数据按 8:2 切分，测试集那 20% 训练全程不接触，只在最终评估用一次；训练过程中调参、选轮次只看验证集。切分用固定随机种子，两个模型切分完全一致，保证对比公平。

**Q3：数据集多大？正负样本均衡吗？**
酒店评论子集约 7,700 条，好评约 69%、差评约 31%，不均衡。切分时做了分层抽样，保证每份数据里正负比例一致，避免指标失真。

**Q4：你的训练过程遇到过什么问题？怎么解决的？**
三个真实问题：① LSTM 第一版欠训练，差评漏判严重（召回率只有 30.9%），加大模型容量后解决；② 加大容量后学习率偏大，训练曲线震荡，把学习率减半后稳定；③ BERT 第一版微调第 3 轮过拟合（训练准确率还在涨、验证损失反涨），改用学习率 warmup 加线性衰减，并按验证集自动保存最优权重后解决。

**Q5：过拟合是什么？你怎么发现的？**
模型把训练数据"背下来"了，但没学到泛化规律。发现方式：训练集和验证集分开，训练准确率一路上涨、验证集损失却掉头变差，就是这个信号。

**Q6：为什么用这个数据集？多大？**
题目指定 ChnSentiCorp。我选用其中的酒店评论子集（约 7,700 条），与"酒店评论"的题目场景一致，且做了去重、去空清洗。

## 二、模型与原理类

**Q7：LSTM 和 BERT 的区别？为什么 BERT 好？**
LSTM 从零开始，按字符顺序读句子学特征；BERT 是在大规模语料上预训练过的模型，已经具备中文语义理解基础，微调只是让它适配情感分类任务。实验结果也印证：BERT 在差评这种少数类上的召回率高 15.5 个百分点。

**Q8：什么叫"微调"？**
拿现成的预训练模型（bert-base-chinese），在酒店评论数据上用很小的学习率继续训练几轮，让它学会这个具体任务。好处是数据量要求低、训练快（本机半小时内）。

**Q9：「结合上下文理解转折」体现在哪？**
演示里最有说服力的一句："房间很干净，但是服务态度太差，不会再来了"——如果只抓关键词"干净"会判成好评；BERT 输出差评、置信度 98%。对比实验里专门放了 5 句转折句，BERT 对 3 句，LSTM 只对 2 句。

**Q10：文本怎么变成模型能处理的数字？**
BERT 用分词器把句子切成词元、映射成编号，统一截断或填充到 128 长度；LSTM 基线用字符级向量化，中文按单字切分。

**Q11：为什么用 TensorFlow？**
题目硬性要求，模型微调用的是 TensorFlow 生态的 Keras 接口。

## 三、系统类

**Q12：系统是怎么实现的？**
前后端分离：前端 Vue 3 页面，后端 Python FastAPI 接口。部署是单服务——后端一个进程既提供预测接口又托管前端页面，一条命令启动。模型在服务启动时加载进内存，只做推理，不含训练逻辑。

**Q13：置信度是怎么来的？**
模型输出的是"这条评论是好评"的概率，超过 50% 判好评，置信度取概率较大一方的百分比展示。

**Q14：系统还有什么不足？**
如实讲两个边界：① 不含情感词、全靠常识的隐式负面会误判，比如"枕头底下有个避孕套"被判成好评；② 部分转折句两个模型都会错，比如"服务很热情，可惜隔音太差"。原因是没有显式情感词时需要世界知识，这超出了当前数据和模型的覆盖范围。

## 四、压力与开放类

**Q15：如果给你更多时间/资源，怎么改进？**
三个方向：① 换用社区标准完整版数据集（约 1.2 万条，含官方切分），训练数据多 55%，预期准确率更高；② 换 RoBERTa-wwm-ext 等更强的中文预训练模型；③ 从二分类扩展到按"位置/服务/卫生"分维度的细粒度分析。

**Q16：为什么你的数据集只有 7,700 条，不是说约 1 万条吗？**
ChnSentiCorp 有不同分发版本：我用的酒店评论子集是 7,700 多条，贴合题目场景；完整版约 1.2 万条，混合了图书、电脑评论。为了贴合"酒店评论"的选题，选了前者，论文里如实说明。

**Q17（老师现场出题，系统当场判错）怎么办？**
不要慌，主动接住："感谢老师，这个例子正好是模型的边界情况——它不含显式情感词，需要常识判断，我的论文第 X 章分析过这类失败案例。"主动展示对局限的理解，比回避更能体现工作量。
