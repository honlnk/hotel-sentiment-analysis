# 酒店评论情感分析系统 - 需求文档（v1）

> 状态：草案（2026-10-31 修订） | 日期：2026-10-30 | 阶段：实施

---

## 一、项目概述

### 1.1 一句话定位

一个**中文酒店评论情感分析系统**：用户输入一条酒店评论，系统自动判断它是「好评」还是「差评」，并给出置信度。系统由两部分组成——一个用深度学习训练出来的情感分类模型，以及一个加载该模型、可现场演示的 Web 应用。

### 1.2 背景

- 这是朋友的**本科毕业设计**，题目为《基于文本挖掘的酒店评论情感分析系统的设计与实现》，由本人协助开发。题目由老师口头给定，没有任务书等书面文件，以下要求均来自与老师的沟通记录及朋友转述的课题描述。
- 课题描述中的技术要求：
  - 使用 **TensorFlow** 深度学习框架；
  - 使用公开数据集 **ChnSentiCorp**（中文情感语料库，约 1 万条已标注正负面的评论）；
  - 模型采用 **LSTM 或 BERT** 一类的深度学习结构；
  - 模型必须**结合上下文理解语义和转折**，而不是单纯抓取情感词语。例如「房间很干净，**但是**服务态度太差」应判定为差评——简单的关键词方法只看到「干净」就会误判为好评。
- 老师对准确率的直接要求：**最后需要做一个模型对比**，准确率以多个模型的横向对比呈现，未设分数线。
- 开发者背景为 Web 开发，此前无模型训练经验；机器为 MacBook Air（Apple M4，16 GB 统一内存），本地训练可行性已确认。

### 1.3 目标

- 训练一个高准确率的中文评论二分类模型（训练集/测试集分离，测试集准确率作为报告指标）；准确率不设硬性分数线，以 LSTM 与 BERT 的模型对比呈现（老师要求），93% 为立项时自定的冲刺参考线；
- 提供一个 Web 演示系统：输入评论文本，实时返回情感结论与置信度；
- 全流程可复现：数据、训练脚本、模型文件、演示系统齐备，支撑毕业设计答辩。

### 1.4 非目标

- 不做多分类、细粒度情感（如按「位置/服务/卫生」分维度打分）；
- 不做模型自研结构创新，直接微调开源预训练模型；
- 不做高并发生产级部署，单机演示即可。

## 二、需求范围

系统分为两个相对独立的部分。

### 2.1 模型侧：训练情感分类模型

| 事项 | 说明 |
|------|------|
| 数据 | ChnSentiCorp 公开数据集的**酒店评论子集**（ChnSentiCorp_htl_all，清洗后约 7,700 条），每条样本为一段中文评论文本 + 正面/负面标签。完整版约 1.2 万条、混合酒店/图书/电脑三个领域；选用酒店子集以贴合题目场景，代价是测试成绩无法与公开文献的完整版成绩直接对比 |
| 数据切分 | 约 80% 用于训练（内部再划出约 10% 作验证集，用于观察过拟合、保存最优权重），20% 留作测试（训练全程不接触，仅在最终评估使用一次）；LSTM 与 BERT 使用同一切分，保证对比公平 |
| 文本处理 | 文本转为固定长度的数字序列（模型不直接认识汉字） |
| 模型结构 | 首选 **BERT 中文预训练模型微调**（理解上下文能力最强，最贴合题目对「转折」的要求）；**LSTM 作为基线**——既跑通全流程兜底，也充当模型对比的参照 |
| 训练 | 全量数据跑 3 轮左右，在本机约 20~40 分钟 |
| 评估 | 在测试集上计算准确率；**LSTM 与 BERT 做模型对比**（老师明确要求），准确率不设外部分数线 |
| 产物 | 一个可加载的模型文件，供 Web 系统调用 |

### 2.2 系统侧：Web 演示应用

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 评论分析 | 输入框填写评论，点击分析后返回「好评/差评」结论与置信度 | P0 |
| 结果展示 | 置信度以百分比呈现，正负面用颜色区分 | P0 |
| 历史记录 | 保存最近的分析记录，便于答辩时回看 | P1 |
| 批量示例 | 内置若干典型例句（含转折句式），一键填入演示 | P1 |
| 准确率看板 | 展示测试集评估指标（准确率、混淆矩阵） | P1（答辩加分项） |

典型使用流程：用户在页面输入评论 → 后端加载已训练的模型进行预测 → 页面展示情感结论与置信度。

## 三、技术选型与约束

| 项 | 选择 | 理由 |
|------|------|------|
| 深度学习框架 | TensorFlow | 题目硬性要求 |
| 模型 | BERT 中文预训练模型（首选）/ LSTM（保底） | BERT 对转折、上下文的理解显著更好，微调成本低 |
| 数据集 | ChnSentiCorp 酒店评论子集 | 题目指定数据集的酒店领域子集，公开且已标注，贴合题目场景 |
| Web 系统 | 前端 Vue 3（JavaScript）+ 后端 FastAPI（Python），单服务部署 | 前端主流轻量；后端与模型同语言，可直接加载训练产物；一条命令启动便于现场演示 |
| 训练环境 | 本机 macOS + Apple M4，启用 Metal GPU 加速 | 已验证可行，无需租用云 GPU |

**本机约束：**

- 16 GB 统一内存由 CPU/GPU 共享，训练时需关闭大内存应用（如浏览器），避免内存不足；
- MacBook Air 为无风扇设计，长时间满载会降频，但本任务单次训练仅 20~40 分钟，影响可忽略。

## 四、阶段规划

| 阶段 | 内容 | 产出 |
|------|------|------|
| 一、环境与数据 | 安装训练环境，下载 ChnSentiCorp 并完成读取、切分、预处理 | 可复用的数据准备脚本 |
| 二、模型训练 | 跑通 LSTM 基线 → 微调 BERT → 对比评估 | 模型文件 + 测试集准确率报告 |
| 三、Web 系统 | 后端加载模型提供预测接口，前端做分析页面 | 可现场演示的系统 |
| 四、答辩材料 | 整理设计思路、实验对比、演示脚本 | 毕设报告素材 + 演示流程 |

> 先用 LSTM 跑通全流程拿到基线，再用 BERT 提升准确率——即使 BERT 环节出问题，也始终有一个能用的模型兜底；两者的对比正是老师要求的「模型对比」。
